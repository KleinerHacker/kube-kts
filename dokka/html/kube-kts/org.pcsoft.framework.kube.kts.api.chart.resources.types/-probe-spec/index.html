ProbeSpec

data class ProbeSpec(val action: ProbeSpec.ProbeAction, val initialDelaySeconds: Duration?, val periodSeconds: Duration?, val timeoutSeconds: Duration?, val successThreshold: Int?, val failureThreshold: Int?, val terminationGracePeriodSeconds: Duration?)

Describes a health check the kubelet performs against a container.

A probe pairs one action - how the check is carried out - with the timing that governs how often it runs and how many results are needed before the container's state flips.

In the rendered YAML the action is not nested under an action key; it becomes a sibling of the timing fields whose key names the action type. This flattening is performed by ProbeSpecSerializer.
